# La Defensa de los Portales

Esta carpeta está preparada para publicar el juego en GitHub Pages. Los HTML, JavaScript, estilos, mapas y todas las ilustraciones HD están juntos en el directorio raíz; las referencias a imágenes son relativas, así que funcionan también bajo la dirección de un repositorio.

## Publicar

1. Sube todos los archivos de esta carpeta al directorio raíz de tu repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, elige la rama principal y la carpeta **/(root)**.
4. Guarda y abre la dirección que GitHub Pages te muestre. La página inicial es `index.html`.

No subas solo los HTML: los archivos `.png` y `.webp` de las texturas también tienen que quedar junto a ellos en el repositorio.

## Abrir en Windows

Haz doble clic en `iniciar.bat`. Necesitas Python 3 instalado. También puedes abrir `index.html` desde GitHub Pages; para esa versión no hace falta Python.
